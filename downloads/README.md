# تحميل حزمة Taleb-Talta-V3

## الملف

**`Taleb-Talta-V3.zip`** — 291 ملف، حجمه حوالي 6.5 ميجا.

التطبيق في جذر الحزمة، وملف `render.yaml` في الجذر مباشرة — جاهز للرفع على مستودع
[`Taleb-Talta-V3`](https://github.com/lolooooo2025-lab/Taleb-Talta-V3) ثم النشر على Render.

**لا يحتوي على أي متغيرات سرية** (تم فحصه مقابل كل القيم الخاصة قبل النشر).

## التحميل

- من صفحة الملف على GitHub: افتح `Taleb-Talta-V3.zip` ثم اضغط **Download / View raw**.
- أو رابط مباشر:
  `https://github.com/lolooooo2025-lab/moodle/raw/arena/554c1e0a-moodle/downloads/Taleb-Talta-V3.zip`
- أو من صفحة الإصدارات (Releases) لنفس المستودع.

## التحقق من سلامة الملف

القيمة الموجودة في `SHA256SUMS.txt`:

```bash
sha256sum Taleb-Talta-V3.zip
```

## بعد التحميل

1. فك الضغط.
2. ارفع **محتويات المجلد** — وليس المجلد نفسه — إلى جذر مستودع `Taleb-Talta-V3`.
3. تأكد أن `render.yaml` في جذر المستودع.
4. Render: **New ← Blueprint** ← اختر المستودع ← الفرع `main`.
5. أدخل القيم السرية في **لوحة Render فقط** — ملف الأسرار يُسلَّم بشكل منفصل ولا يُرفع على GitHub أبدًا.
